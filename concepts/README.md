**Learning objective:** By the end of this lesson, students will be able to connect common interface problems to appropriate CSS tools.

## Help the player understand the page

Imagine opening a delivery website on your phone. A panel runs off the screen. A button looks available even though you cannot use it. The page has information, but using it takes extra effort.

Our games can have the same problems.

We will use a small set of tools to make the interface easier to understand:

| Problem | Useful tool |
| --- | --- |
| Adding padding makes a panel wider than expected | `box-sizing` |
| Every project needs the same basic styles | CSS boilerplate |
| Text needs a consistent appearance | Fonts |
| Players need feedback when using buttons | Pseudo-classes |
| A style affects more elements than intended | Child selectors |
| Sizes need to relate to text or screen space | Relative units |
| Cards need organized rows and columns | Grid |

You do not need to use every tool in every project. Learn the problem each tool solves so you can recognize when it will help.
